This site is the product of a **software factory** built for the Secure Software
Development Lifecycle course at UPT.

Nobody edits these pages by hand. A post starts as a ticket (a GitHub issue).
A writing agent turns the ticket into a pull request, the pipeline builds and
tests it, a second agent reviews it with a fresh context, and a named person
approves the deploy to production.

The factory's source, its pipeline and its audit log are public in the
repository.
